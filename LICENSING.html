Yanfei licensing

Yanfei is a modified version of Felucca. The fork source is https://github.com/izumoe/yanfei. The upstream notices and component licences below remain applicable.

What is GPL-3.0-only

Every file in this tree that carries an SPDX-License-Identifier: GPL-3.0-only header:

  • the firmware: firmware/ (app, HAL, update loader; not firmware/engines/, MIT: below)
  • the build script and tools: build.sh, tools/ (not tools/gen_waves.py, the Hügelton Sample Pack: CC0 1.0, below)
  • the web pages (installer, editor, the browser emulator web/emu/) and their tests: web/ (not the Fukiai and DotGothic16 fonts, below)
  • the host tests: tests/

Three source files are ports and keep the licence of their originals: firmware/src/phys_dsp.c (DaisySP, MIT), firmware/src/phys_symp.c (Rings, MIT) and firmware/src/fm6_core.c (msfa, Apache-2.0). The firmware built with them is GPL-3.0-only as a whole.

Five engines and the code they share are under the MIT licence, not the GPL. They are Hügelton Instruments' own work and live in their own repository, Felucca-Engines (https://github.com/hugelton/Felucca-Engines), included here as the git submodule firmware/engines/: the ANALOG, LOFI, TRIO, WHEEL and NOISE engines (eng_analog.c, eng_lofi.c, eng_trio.c, eng_wheel.c, eng_noise.c), the engine interface (felucca_engine.h), the shared DSP helpers (dsp.c) and the generator of their tables (SPDX-License-Identifier: MIT, firmware/engines/LICENSE, also LICENSES/MIT-Felucca-Engines.txt). The firmware built with them is GPL-3.0-only as a whole. Felucca's complete source includes that submodule: clone with --recurse-submodules, and give it along with the rest when you share the source. Each release also offers felucca-X.Y.Z-source.tar.gz, the whole source with the submodule's files in it (GitHub's own source archives leave the submodule empty).

You may use, study, change and share Felucca under the GPL. If you distribute Felucca, or firmware derived from it, you must also give your recipients its complete corresponding source under the same licence. That includes devices that ship with modified Felucca inside.

JieLi SDK files in the packages (Apache-2.0)

A .fwsc package made by tools/build.py (with tools/fm1pkg_make.py; this is the package the web installer installs) holds three unmodified files from the JieLi AC79 SDK (https://gitee.com/Jieli-Tech/fw-AC79_AIoT_SDK, cpu/wl82/tools/). They are read from your SDK checkout at build time (see BUILDING.md); no SDK files are in this tree.

File in the package What it is
uboot.boot the first-stage boot loader (SPL)
cfg_tool.bin the chip configuration block
eq_cfg_hw.bin the default hardware EQ table

They are licensed under the Apache License, Version 2.0 (LICENSES/Apache-2.0.txt), not under the GPL, and their copyright stays with JieLi Technology. The SDK has no NOTICE file. Apache-2.0 files may be distributed together with GPL-3.0 code; Felucca itself stays GPL-3.0-only.

Every distribution of a package carries the licence texts with it: the release folder (tools/build.py --release) and the site (web/make_site.py, next to the package in firmware/ and linked from the installer page).

No vendor material

No M-VAVE material is part of Felucca. The firmware links no vendor code and contains no vendor data, and the packages hold only Felucca and the three SDK files above. The installer's "Return to official V15" holds only the official file's size and SHA-256: you select the official firmware file you downloaded yourself, and it is checked and installed in your browser, never uploaded or redistributed.
