Yanfei

Yanfei is custom firmware for the M-VAVE FM-1. It is based on Felucca by Leo Kuroshita and Hügelton Instruments. The fork source is izumoe/yanfei.

Yanfei has twelve engines, 96 factory presets, and a four-track tracker. The tracker starts in ALL. Press SHIFT + UP to open detailed PHRASE. Use shared phrases, chains, and song sections to arrange music.

Build

Follow BUILDING.md to install the toolchain and SDK. Then run:

./build-yanfei.sh

The installable package is build/yanfei.fwsc. The app image is build/yanfei.bin. The existing ./build-core.sh command also builds Yanfei. The package retains the FM-1 update identity required by the installer.

For the browser emulator, activate Emscripten, then run:

FELUCCA_CORE=1 sh web/emu/build.sh
python3 -m http.server 8000 --directory build/emu

Open http://localhost:8000 in Chrome or Edge. The internal build flag keeps its existing name for compatibility.
