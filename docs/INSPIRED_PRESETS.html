Core6 inspired factory presets

Core6 adds 60 original patches to the default set: eight presets per engine, 96 total. The existing three per-engine preset indices and sounds are retained; the new sounds occupy positions 4–8 on each engine. No user-bank import is needed after installing core6.

The references describe a timbral direction. These are original parameter/operator recipes, using the engines already present, with no factory ROM patches, samples or game melodies. The acoustic STRING/MODAL additions draw on instrument-like sounds used in early digital and physical-modelling synths. Drum presets tune the existing synthesis models.

Compatibility and size

Existing engine IDs, project/user-preset formats and the first three factory indices are unchanged. Core5/core6 audio comparison checks all original 36 sounds through note-on, release and effects. The expanded global preset browsing/program-change order includes the appended sounds; saved projects and user presets carry their own sound parameters.

FM6 keeps F1–F3, OWN=3 and B1–B32=4–35. The five new full six-operator factory voices load into OWN, and their actual operator patch is included in projects, user presets and the optional desktop-library export. YM has separate operator settings for all eight voices.

The app grows from 405,784 to 408,704 bytes: 2,920 bytes. Ordinary RAM remains 52,280/73,728 bytes and the shared buffer pool 328,896/368,640. No recorded audio is included in firmware. Hardware timing still needs checking on a device.

Audition and validation

build/core6/highlights.mp3 is a 48-second sampler (first new patch from each engine). build/core6/preset-auditions.zip contains an offline HTML catalog and all 60 four-second clips. Clips use a short original phrase, the actual sound loader/mixer/effects and the presets' own levels; they are not loudness-normalized.

The optional factory-library.json is a desktop-library backup of all 96 defaults. The firmware already contains them; the hardware user bank still has 32 slots.

All 96 presets render with distinct per-engine signatures, release and round-trip through user-preset/project NOR storage. 232 independent mixer cases have no PCM rail hits; 27 two-core scenes match one core at every tested split. The new preview clips are also checked for finite, audible, unclipped output.

To regenerate host audition assets after building the generated headers:

cc -DFELUCCA_CORE=1 -fwrapv -O2 -ffp-contract=off -w -Ibuild/gen -Ifirmware/src \
  tools/render_factory.c -lm -o build/host/render_factory
mkdir -p build/core6
build/host/render_factory --list > build/core6/factory-manifest.json
python3 tools/make_factory_previews.py build/core6
node tests/core_factory_library.mjs build/core6/factory-library.json
node tests/core_factory_compat.mjs build/core5/felucca.wasm build/emu/felucca.wasm
