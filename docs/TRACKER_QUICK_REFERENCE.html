Yanfei tracker quick reference

Start with the visual guide for the keyboard map and screen pictures. See the user guide for procedures and examples.

ALL is the default tracker view after a restart. The tracker keeps your selected view during the current session. Hold SHIFT and press UP to switch between ALL and detailed PHRASE. In ALL, LEFT and RIGHT select a track. UP and DOWN select a row. Use REC note entry to replace the cell with one note, a chord, or drum hits. PRESETS and EDIT with arrows transpose the whole chord. SHIFT + OPTION copies the row. SHIFT + EDIT pastes it. OPTION + EDIT clears it. PLAY repeats the selected section. SHIFT + PLAY starts the song. A new section has four pages: 64 rows at DIV 1/16, or four bars. SELECT and UP/DOWN scroll across pages. SHIFT + SELECT changes page. One or two notes show their pitches. Larger sets show a chord name or MULTI. See Use the four-track view for details.

Press SEQ to cycle the tracker, STEP, DETAIL, and AUTOMATION pages. In section editing, the heading shows the page number. In separate PHRASE editing, it shows the engine and phrase number. The table shows N1 through N4, or KD through RM. In PHRASE and ALL, the bottom strip shows CH (chance), RT (ratchet), ND (nudge), and VEL (velocity) for the selected row. KNOB 1 through KNOB 4 still control the sound in PHRASE.

Pasted references share the original item. A cloned chain still shares its phrases. A cloned phrase still shares its instruments. Row paste includes notes, instrument, gate, and step settings. Existing automation at the destination stays in place. Phrase clone also copies automation.

DETAIL and save

Press SEQ until DETAIL appears. Turn PRESETS to select the row.

Knob Field
KNOB 1 CHANCE / condition
KNOB 2 RATCH, one through four repeats
KNOB 3 NUDGE, early or late timing
KNOB 4 VEL

NUDGE requires QUANTIZE OFF and RATCH set to one. Set QUANTIZE on the AUTOMATION page.

To save a whole project:

  1. Stop playback.
  2. Press SAVE until PROJECT appears.
  3. Select the slot with KNOB 1.
  4. Turn KNOB 4 right to select SAVE.
  5. Press OCT+.
  6. Follow the overwrite and name prompts.
  7. Press OCT+ on NAME to write the project.

To load, select LOAD with KNOB 3 on PROJECT, then press OCT+. Loading replaces current work. SAVE > USER saves a sound, not the complete project.

Fixed section lengths use musical time, independent of track LEN, DIV, and SWING. At other divisions, a page is not necessarily one bar. A shorter section keeps notes on later pages. SONG shows R for REPEAT and W for WAIT beside each track. AUTO preserves the previous finish-all-chains timing for old projects. Browsing blank pages uses no phrase slots. Written pages and clones share the project's limit of 32 phrases. Pasting a page shares the source phrase. Clone a shared chain in SONG before you change pages for only one section.
